# Mes scripts

Scripts Bash que j'utilise pour accompagner mes résolutions de machines Hack The Box et mes travaux en environnement CTF.

## Scripts disponibles

- **[mon-nmap](https://writeups.hackethical.be/mes-scripts/mon-nmap/)** — automatisation de l'énumération réseau avec Nmap.
- **[mon-recoweb](https://writeups.hackethical.be/mes-scripts/mon-recoweb/)** — reconnaissance et énumération d'applications web.
- **[mon-subdomains](https://writeups.hackethical.be/mes-scripts/mon-subdomains/)** — recherche de sous-domaines et Virtual Hosts.
- **[make-htb-wordlist](https://writeups.hackethical.be/mes-scripts/make-htb-wordlist/)** — génération de la wordlist utilisée par `mon-subdomains`.

Chaque lien mène à la présentation détaillée du script, son utilisation et sa version courante.

## Téléchargements

Les versions publiées des scripts ainsi que leurs empreintes SHA256 sont disponibles dans les Releases de ce dépôt.

Ce dépôt est synchronisé automatiquement depuis mon environnement de développement.
